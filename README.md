# آني - Ani Social

منصة تواصل اجتماعي عربية حديثة مبنية بتقنية React و Vite و Tailwind CSS.

## المميزات الأساسية
- **شريط القصص (Stories)**: استعراض قصص الأصدقاء بملء الشاشة، مؤشرات المشاهدة، وإمكانية إضافة قصة جديدة.
- **خلاصة المنشورات (Feed)**: دعم المنشورات النصية والصور، التفاعل بالإعجاب مع حركات تفاعلية، حفظ المنشورات، ومشاركتها.
- **التعليقات والردود المترابطة (Threaded Comments Drawer)**: فتح شريط تعليقات تفاعلي مع دعم الردود المتداخلة وإرفاق الصور مع التعليقات.
- **إنشاء المنشورات (Post Creator)**: نافذة سريعة لكتابة المنشورات، إرفاق الصور، واختيار الوسوم.
- **مساعد آني الذكي (AI Assistant)**: نافذة ذكاء اصطناعي تفاعلية تقدم أفكاراً للمنشورات، صياغات ترحيبية، واقتراحات وسوم.
- **البحث والاستكشاف (Search & Discovery)**: البحث في المنشورات والأشخاص، واستعراض المواضيع الرائجة (#هاشتاقات).
- **الملف الشخصي (Profile)**: إدارة معلومات الحساب، إحصائيات المتابعين والمنشورات، تبويبات المنشورات والإعجابات والمحفوظات، وتعديل البيانات.
- **شريط الإشعارات (Notifications)**: متابعة التفاعلات الجديدة وتحديد الكل كمقروء.

## التشغيل محلياً
```bash
npm install
npm run dev
```
يعمل خادم التطوير على المنفذ `3000`.
